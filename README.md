# Blinkit Clone

A simple **Blinkit (Grocery Delivery App) Clone** created using only **HTML** and **CSS**.  
This project is made for practice purposes to improve frontend skills and learn website layout design.

---

## 🚀 Features
- Responsive design using media queries
- Header with navigation
- Product categories section
- Cards for products with images and details
- Footer section

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
